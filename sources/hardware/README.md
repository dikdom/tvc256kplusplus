# hardware - Hungarian

Ez a folder tartalmazza a nyáklap tervezési forrás fájljait. A terveket az EasyEDA webes felületén készítettem, ez az exportált kapcsolási rajz és nyákterv. Módosítsd kedvedre, de
a nevemenet (és ezt a repot) ne felejtsd el közzéteni, ha forgalmazni is szeretnéd.

# hardware - English
This folder contains the PCB's source files: the schematics and the PCB plans. I have designed them in the EasyEda web based designer program, these are the exported files. You can modify
these but if you plan to sell/redistribute then you have to note my name (and this repo)
